# Security

Do not file public issues for vulnerabilities.

Report security problems privately via GitHub Security Advisories on
[GEM-Industries/JARV1S](https://github.com/GEM-Industries/JARV1S/security/advisories/new)
once that repository is public, or by emailing the maintainers listed on the
organization profile.

Please include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept if you have one
- Affected versions or commit if known

We will acknowledge the report and work on a fix before any public disclosure.
