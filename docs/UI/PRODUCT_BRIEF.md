# JARV1S Product Experience Brief

The intended experience across voice, screens, and ambient interactions. Holographic direction lives in [`VISUAL_LANGUAGE.md`](./VISUAL_LANGUAGE.md); visual implementation lives in [`STYLE_GUIDE.md`](./STYLE_GUIDE.md); foundations live in code and are inventoried in [`FOUNDATIONS.md`](./FOUNDATIONS.md).

## Experience

JARV1S should feel like a fast, reliable assistant woven into daily life: available wherever the user is, integrated with the systems they already use, and capable of acting on their behalf.

It is ambient intelligence, not a chatbot. Voice is the primary way to interact; screens complement it with detail, confirmation, correction, and control. The interface appears when useful and recedes when it is not.

## Product principles

1. **Lead with the useful outcome.** Start with the answer, result, or recommended action. Reveal supporting detail when it helps the user decide or when they ask for it.
2. **Adapt to context; preserve familiarity.** Tailor content, density, modality, and suggested actions to the person, task, environment, and available surface. Keep interaction patterns familiar so adaptation never becomes unpredictability.
3. **Act like one integrated assistant.** Let users delegate goals instead of managing providers, plugins, devices, or internal state. Carry relevant context across connected systems and surfaces.
4. **Be fast, competent, and clear.** Respond immediately when possible. For longer work, acknowledge it, continue without blocking the user, and communicate meaningful progress. State changes should feel composed and preserve continuity.
5. **Earn autonomy and attention.** Act on safe, reversible work; confirm consequential actions. Be proactive when context warrants it, while respecting the user's attention choices and established delivery policy.
